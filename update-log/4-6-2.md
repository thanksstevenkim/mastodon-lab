# Mastodon 4.6.2 Upgrade

## Upgrade date: 2026-06-25 21:03 KST

## Previous version: 4.5.11

## Target version: 4.6.2

## Downtime

Approximately 40-60 minutes

Reason:

- Multiple build failures during the upgrade
- Ruby runtime upgrade
- Database migration troubleshooting

## Backup performed: Auto-backup

## Update procedure:

1. git fetch upstream
2. git merge --no-ff v4.6.2
3. Resolve merge conflicts
4. bundle install
5. yarn install
6. git push
7. docker build -t mustardkim/mastodon-mustard:v4.6.2 .
8. docker build -f streaming/Dockerfile -t mustardkim/mastodon-mustard:v4.6.2-streaming .
9. docker tag mustardkim/mastodon-mustard:v4.6.2 mustardkim/mastodon-mustard:latest
10. docker push mustardkim/mastodon-mustard:v4.6.2
11. docker push mustardkim/mastodon-mustard:latest
12. docker push mustardkim/mastodon-mustard:v4.6.2-streaming
13. cd /opt/mastodon
14. sudo nano docker-compose.yml
15. Replace 4.5.11 into 4.6.2
16. docker compose pull
17. docker compose down && docker compose up -d

## Notes

- Major upgrade from 4.5.x to 4.6.x.
- Theme implementation changed and existing theme became incompatible.
- Ruby runtime upgrade required.
- Verify database migrations before starting production containers.

## Lessons learned

- Review runtime and database requirements before major upgrades.
- Minimize local modifications to upstream source files.
- Treat migration and post-deployment verification as mandatory deployment steps.
