# Mastodon 4.6.5 Upgrade

## Upgrade date: 2026-07-29 16:24 KST

## Previous version: 4.6.4

## Downtime: Less than 5 minutes

## Backup performed: Auto-backup

## Update procedure:

1. git fetch upstream
2. git merge --no-ff v4.6.5
3. git push
4. docker build -t mustardkim/mastodon-mustard:v4.6.5 .
5. docker build -f streaming/Dockerfile -t mustardkim/mastodon-mustard:v4.6.5-streaming .
6. docker tag mustardkim/mastodon-mustard:v4.6.5 mustardkim/mastodon-mustard:latest
7. docker push mustardkim/mastodon-mustard:v4.6.5
8. docker push mustardkim/mastodon-mustard:latest
9. docker push mustardkim/mastodon-mustard:v4.6.5-streaming
10. cd /opt/mastodon
11. sudo nano docker-compose.yml
12. Replace 4.6.4 into 4.6.5
13. docker compose pull
14. docker compose down && docker compose up -d
