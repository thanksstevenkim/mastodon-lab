# Mastodon 4.6.6 Upgrade

## Upgrade date: 2026-07-29 16:24 KST

## Previous version: 4.6.5

## Downtime: Less than 5 minutes

## Backup performed: Auto-backup

## Update procedure:

1. git fetch upstream
2. git merge --no-ff v4.6.6
3. git push
4. docker build -t mustardkim/mastodon-mustard:v4.6.6 .
5. docker build -f streaming/Dockerfile -t mustardkim/mastodon-mustard:v4.6.6-streaming .
6. docker tag mustardkim/mastodon-mustard:v4.6.6 mustardkim/mastodon-mustard:latest
7. docker push mustardkim/mastodon-mustard:v4.6.6
8. docker push mustardkim/mastodon-mustard:latest
9. docker push mustardkim/mastodon-mustard:v4.6.6-streaming
10. cd /opt/mastodon
11. sudo nano docker-compose.yml
12. Replace 4.6.5 into 4.6.6
13. docker compose pull
14. docker compose down && docker compose up -d

## Post-upgrade maintenance

Several GitHub Actions failures that had existed in the fork were investigated after the upgrade.

The failures were not caused by the 4.6.6 upgrade itself. They were traced to:

- outdated Ruby dependencies with published security advisories
- stale theme customizations affecting CSP behavior
- a modified hashtag normalizer that differed from upstream 4.6.6
- JavaScript lint configuration that unintentionally included JSX files
- a stray lint script in the streaming workspace

The fork was realigned with upstream 4.6.6 where appropriate, and security-related dependencies were backported from newer upstream commits.

All relevant GitHub Actions checks passed after the cleanup.
